# 旅迹｜世界足迹地图设计规格

> 状态：已实现并验收  
> 版本：V0.2  
> 影响路径：访客首页 `/`  
> 管理端 `/admin/` 不受影响

## 1. 决策摘要

首页进一步收敛为旅行内容本身：移除顶部品牌导航和左侧大标题/统计区，保留目的地索引、旅程详情及相册。在相册之后、页脚之前新增编辑式世界足迹地图。

地图不接入第三方地图服务。世界轮廓使用内联 SVG 绘制，足迹使用可聚焦的 HTML 标记覆盖在地图上，以保证键盘、触控和屏幕阅读器体验。

## 2. 页面结构调整

### 2.1 移除

- 整个顶部 `.site-header`：品牌、足迹、相册、关于导航全部移除。
- 首屏 `.hero-copy`：`PERSONAL ATLAS`、大标题和城市/国家/照片统计全部移除。
- 与上述区域相关且不再使用的 CSS。

保留页面开头的“跳到主要内容”无障碍链接。

### 2.2 保留并重排

1. 目的地索引成为页面第一视觉区，保持四张目的地卡片及悬停预览。
2. 当前旅程详情继续展示路线、主图、日期与简短说明。
3. 相册继续与当前旅程同步，并保留灯箱。
4. 世界足迹地图位于相册之后。
5. 页脚位于地图之后。

## 3. 地图视觉设计

- **标题**：`世界足迹`；英文元数据为 `WORLD ATLAS / 04 JOURNEYS`。
- **世界轮廓**：抽象但可辨识的大陆剪影，使用墨灰色细描边和极低透明度填充。
- **背景**：沿用温暖石灰白纸张底色，叠加稀疏经纬网格和轻微纸张纹理。
- **构图**：地图占据页面宽度约 80%—100%，标题与旅程计数形成不对称编辑排版。
- **标记**：圆点与细环构成，不使用图钉、旗帜或邮戳符号。
- **当前旅程**：使用该旅程的强调色、扩大外环并显示常驻城市标签。
- **其他旅程**：默认使用墨灰色；悬停或聚焦后显示强调色和标签。
- **动效**：标记外环使用 180—260ms 的缩放与透明度过渡；不使用持续脉冲动画。

## 4. 坐标与投影

每段旅程在 `src/trips.js` 中增加数值坐标：

```js
geo: { latitude: 35.0116, longitude: 135.7681 }
```

地图采用等距圆柱投影：

```text
x = (longitude + 180) / 360 × 100%
y = (90 - latitude) / 180 × 100%
```

数值坐标只用于视觉定位；现有 `coords` 字符串继续负责界面文字展示。地图不是测绘工具，不提供路线距离或行政边界精度承诺。

## 5. 交互规则

### MAP-01 浏览足迹分布

- 页面进入地图区域时，显示所有具有 `geo` 数据的旅程标记。
- 当前已选择旅程的标记保持高亮，其余标记保持低对比度。
- 地图标题显示当前足迹数量，本版本为 4 段旅程。

### MAP-02 悬停或聚焦标记

- **触发**：鼠标悬停，或键盘 `Tab` 聚焦标记。
- **反馈**：显示城市、国家和旅行日期；外环放大并切换为旅程强调色。
- **边界**：只预览地图标签，不改变当前旅程，也不触发页面滚动。
- **退出**：指针离开或焦点移出后恢复当前选中状态。

### MAP-03 点击标记查看旅程

- **触发**：鼠标点击、触控点击，或聚焦后按 `Enter` / `Space`。
- **主流程**：
  1. 将对应地点设为已确认旅程。
  2. 路线、主图、说明与相册同步更新。
  3. 对应地图标记变为当前状态。
  4. 页面平滑滚动至旅程详情 `#footprints`。
- **减少动态效果**：启用 `prefers-reduced-motion` 时直接跳转，不执行平滑滚动。

### MAP-04 从目的地索引切换旅程

- 用户在页面顶部通过目的地卡片切换后，地图中的当前标记必须同步更新。
- 地图标签不强制滚入视口，避免打断当前浏览任务。

## 6. 组件结构

```text
section.world-map-section#world-map
├── header.world-map-heading
│   ├── p.section-label
│   ├── h2#world-map-title
│   └── p#world-map-meta
└── div.world-map-stage
    ├── svg.world-map-art[aria-hidden=true]
    │   ├── 经纬网格
    │   └── 大陆轮廓
    └── div#map-markers
        └── button.map-marker × N
            ├── span.marker-dot
            └── span.marker-label
```

SVG 只承担视觉表达并对辅助技术隐藏。每个足迹标记使用真实 `<button>`，可访问名称为“查看京都旅程，2026年4月18日”等完整动作描述。

## 7. 状态关系

地图不创建第二套选择状态，复用首页已有的 `selectedId`：

| 行为 | `selectedId` | 旅程内容 | 地图当前标记 |
| --- | --- | --- | --- |
| 索引悬停预览 | 不变 | 临时变化 | 不变 |
| 索引点击/方向键 | 更新 | 更新 | 更新 |
| 地图标记悬停/聚焦 | 不变 | 不变 | 只显示临时标签 |
| 地图标记点击 | 更新 | 更新 | 更新 |

地图渲染函数只读取 `trips` 和 `selectedId`，通过现有 `selectTrip()` 提交选择，避免两套状态发生偏差。

## 8. 响应式与无障碍

- 桌面端地图最小高度约 520px，标记标签可常驻或向外展开。
- 620px 以下地图按完整世界范围缩放，不产生页面级横向滚动。
- 移动端非当前标记只显示圆点，触控或聚焦后显示标签，减少文字碰撞。
- 标记按钮的可点击区域至少 44×44px，视觉圆点可小于命中区域。
- 所有标记都有清晰的 `focus-visible` 外轮廓。
- 不能仅靠颜色区分当前标记：当前项同时扩大圆环并常驻标签。
- 地图区域使用 `aria-labelledby`，足迹数量通过可读文字提供。
- 减少动态效果模式关闭平滑滚动和标记过渡。

## 9. 功能边界

### 包含

- 四段现有旅程的世界位置标记。
- 当前旅程同步、标记信息预览、点击跳转旅程。
- 键盘与触控操作。
- 桌面和移动端响应式布局。

### 不包含

- 地图拖动、滚轮缩放、惯性移动或全屏。
- 第三方地图 SDK、瓦片服务或 API Key。
- 国家着色、访问国家统计和行政边界详情。
- 真实 GPS 轨迹、航线连接、距离或路线动画。
- 从地图新增或编辑地点；编辑仍属于 `/admin/` 的未来范围。
- 聚合点、搜索、筛选或大量足迹性能优化。

## 10. 异常与降级

- 某段旅程缺少 `geo` 时不渲染标记，地图计数按有效坐标计算。
- 坐标超出经纬度范围时忽略该标记，避免落在地图外。
- JavaScript 不可用时地图轮廓和标题仍可见，但交互标记不显示；旅程与相册的现有静态初始内容仍可阅读。
- SVG 不负责传达唯一信息；所有地点文字通过 HTML 标记及地图元数据提供。

## 11. 验收标准

- 首页不存在 `.site-header`、品牌导航、`.hero-copy`、大标题或统计区。
- 页面顶部直接展示目的地索引，视觉层级自然且无大面积无意义空白。
- 相册后、页脚前显示世界足迹地图。
- 地图正确标记里斯本、京都、冰岛和巴黎的大致位置。
- 四个标记可通过鼠标、触控和键盘访问。
- 悬停或聚焦标记只显示标签，不改变已确认旅程。
- 点击标记会选择对应旅程、同步内容并移动至旅程详情。
- 从顶部索引切换旅程后，地图当前标记同步变化。
- 375px 与桌面宽度均无页面级横向溢出。
- 启用减少动态效果后不执行平滑滚动，所有任务仍可完成。
- 首页既有旅程切换、相册灯箱和 `/admin/` 管理端不回归。
- 自动化测试、语法检查与浏览器冒烟测试通过，控制台无错误。
