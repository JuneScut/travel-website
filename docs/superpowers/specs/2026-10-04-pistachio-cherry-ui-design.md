## 1. 设计决策

用户要求使用粉色等明亮色彩，具有艺术设计感和活泼气质，可使用衬线字体，并融合项目现有的邮票设计。

最终选择「开心果樱桃独立刊物」：以摄影独立刊物为构图方向，采用开心果色刊头、樱桃红大字、草莓粉齿孔邮票及浅色阅读背景。摄影承担主要叙事，邮票承担旅程选择，细分隔线建立刊物的阅读秩序。

V0.2 在不改变配色与版式的前提下补充动效：动效借用「刊物与邮政」的物理隐喻——发牌、盖戳、翻页幕布、航线——让每一次交互都有明确的因果，而不是装饰性循环。

### 实测对比度（WCAG 2.x 公式）

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| 墨绿 / 浅叶白 | 9.67 : 1 | 正文可用 |
| 墨绿 / 开心果 | 8.11 : 1 | 刊头文字可用 |
| 墨绿 / 草莓粉 | 5.56 : 1 | 页脚文字可用 |
| 次要文字 `#4F6C5B` / 浅叶白 | 5.49 : 1 | 小字可用（V0.2 由 72% 调整为 80% 混合，原值 4.44 不达标） |
| 樱桃红 / 浅叶白 | 3.92 : 1 | 只用于 ≥ 24px 的展示标题、图形和非唯一的状态标记；不得用于正文小字 |
| 樱桃红 / 草莓粉 | 2.25 : 1 | 只用于装饰图形，不承载文字 |

### 使用原则

1. 全站配色固定；切换目的地只更新旅行内容和邮票状态，不将全站强调色替换成城市原有的色值。
2. 开心果、樱桃红和草莓粉用于刊头、标题与艺术图形；正文使用墨绿，保留浅色阅读区域。
3. 选中状态同时提供位置变化、文字标记及颜色反馈，不能仅靠颜色区分。
4. 页面背景、正文、装饰图形和交互强调分别使用语义 token，避免共用一个 accent 变量承担全部用途。
5. 对比度已按上表计算；正式实现仍需在真实字号与透明度下复核，本规格不声称已通过完整无障碍验收。

## 5. 页面结构

```text
刊头：旅迹 JOURNAL ＋ 旅程／沿途光影／世界足迹（吸顶，底部为滚动进度条）
刊物标题：Out of office. ＋ 简短介绍
旅程主区域
├── 邮票索引：里斯本、京都、冰岛、巴黎
└── 当前旅程：主照片、标题、日期、摘要、路线、上一段／下一段
沿途光影：当前旅程的照片集合（三列错落）
世界足迹：真实世界地图（地球 → 街道级缩放）＋ 地点信息卡 ＋ 按时间排列的足迹列表
页脚：草莓粉齿孔底边
```

桌面：左侧两列邮票索引，右侧宽幅主照片，下方排列标题与摘要。以细线划分栏目，避免所有内容包裹在圆角卡片中。相册为宽／中／窄三列，列与列上下错开，照片按序号依次放入三列，不使用负边距叠放。

移动端：邮票索引移至主照片上方，使用两列布局，随后是照片、旅程信息、相册（两列）和地图。V0.2 原型已按此实现，并验证 390px 宽度无横向溢出。

## 6. 邮票视觉

- 沿用现有目的地索引的齿孔轮廓。
- 外框使用草莓粉，内部使用开心果、樱桃红与墨绿构成的圆、弧线和斜切色块。
- 图形随目的地变化，维持统一的配色和画面语言。
- 默认平放；悬停时抬起、倾斜并显示日期；选中后保持略微抬起与反向倾斜。
- **V0.2 新增邮戳**：被选中的邮票右下角盖有樱桃红邮戳（同心圆＋城市与年份环形文字＋三道波浪注销线），作为常驻选中标记。邮戳与抬起位置、名称后的「↗」共同表达选中，不只依赖颜色。
- 原型以 CSS 静态几何图形验证视觉；原项目规划的 Shader 能力可沿用同一配色与齿孔边界，本轮尚未实现 WebGL 动态效果。

### 状态与联动

已选旅程是照片、标题、日期、路线、相册及地图的共同状态来源。悬停邮票只改变局部视觉，离开后恢复；点击才改变已选旅程。连续选择以最后一次为准：每次选择递增一个令牌，照片转场在幕布合拢后检查令牌，过期的转场不会写入照片，因此照片与文字不会出现不同旅程的内容（原型已用连续快速点击四次验证）。

正式实现需修正当前首页在旅程切换时直接写入全局 `--accent` 的逻辑，保证本方案的全站配色稳定。

## 8. 动效系统（V0.2 新增）

### 8.1 原则

1. **因果先于装饰**：每个动效都对应一次加载、选择、滚动进入或打开操作，播放一次后停止。不使用持续晃动、循环脉冲或无限跑马灯。
2. **借物理隐喻**：发牌（邮票落位）、盖戳（选中）、翻页幕布（换照片）、航线（地图）。
3. **内容先就位，动效后表现**：数据在动效开始前同步写入 DOM；动效只改变透明度和位移，不延迟信息本身。
4. **只动合成层属性**：transform、opacity、clip-path、stroke-dashoffset；不对布局属性做动画。
5. **可中断**：新的选择会接管正在进行的动效，从当前位置继续，不会闪回初始状态。

### 8.2 动效 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | 入场、揭示、照片缩放 |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | 幕布、分隔线、航线描绘 |
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | 邮票落位与抬起、地图标记弹出 |
| `--dur-micro` | 160ms | 颜色、标签显隐 |
| `--dur-short` | 280ms | 下划线、悬停反馈 |
| `--dur-medium` | 520ms | 邮票抬起、文字入场 |
| `--dur-long` | 900ms | 照片缩放、滚动出场 |

### 8.3 开场编排（首次加载，约 2 秒）

| 时间 | 元素 | 动效 |
| --- | --- | --- |
| 0ms | 刊头 | 从上方滑入，700ms |
| 180ms 起 | `Out of office.` | 每个字母从遮罩下方升起并回正，间隔 38ms，各 900ms |
| 500ms 起 | 分隔线 | 从左向右描出，1100ms |
| 620ms | 副文案 | 淡入上移 |
| 700ms 起 | 四枚邮票 | 像发牌一样从上方带旋转落下，弹性回位，间隔 110ms |
| 900ms 起 | 主照片 | 开心果、樱桃红两层幕布依次向右拉开，照片从 1.15 倍缩回 |
| 1250ms | 旅程信息 | 淡入上移 |

页面绘制前隐藏开场目标，避免先显示后跳动；字体最多等待 1.2 秒。

### 8.4 选择旅程（核心交互，约 1 秒）

| 时间 | 元素 | 动效 |
| --- | --- | --- |
| 0ms | 编号 `02 / 04` | 数字按切换方向上下翻滚 |
| 0ms | 被选邮票 | 按下回弹（缩至 0.94） |
| 90ms | 邮戳 | 从 1.7 倍带旋转压下，略过冲后定格，380ms |
| 0–490ms | 照片幕布合拢 | 樱桃红层先、开心果层后（间隔 70ms）从左侧盖住旧照片，同时预解码新照片 |
| 合拢后 | 照片幕布拉开 | 换入新照片，开心果层先、樱桃红层后向右拉开；新照片从 1.12 倍缩回 |
| 140ms | 日期栏 | 淡入 |
| 200ms 起 | 旅程标题 | 逐字从下方带 4° 旋转升起，间隔 24ms |
| 320ms | 摘要 | 淡入上移 |
| 420ms 起 | 路线 | 逐站从左侧滑入，间隔 80ms |
| 120ms 起 | 相册（已进入视口时） | 六张照片依次浮现，间隔 60ms |
| 同步 | 地图 | 选中标记变樱桃红并展开虚线圆环 |

### 8.5 悬停与指针

- **邮票**：抬起 10px 并倾斜 3°；按指针位置做最大 ±8° 的 3D 倾斜，内部几何图形反向位移 4–6px 形成视差；日期展开。仅鼠标指针触发。
- **照片**：1.03–1.05 倍缓慢放大；指针设备显示樱桃红圆形「查看／放大」标签，带弹性出现并平滑跟随（仅在可见时运行逐帧跟随，离开后停止）。
- **导航与按钮**：下划线从左向右描出；圆形按钮按下时缩至 0.92。

### 8.6 滚动

- **进度条**：刊头底部 3px 樱桃红进度条随页面滚动伸长（CSS 滚动时间线；不支持的浏览器不显示）。
- **区块出场**：区块标题与相册照片进入视口 20% 时上移淡入，每项延迟 70ms，只触发一次。
- **世界地图**（V0.3 更新，详见第 9 节）：地图在读者距离区块 600px 时才开始加载。载入后地球用 2.8 秒转向四段旅程，同时按时间顺序（冰岛 → 巴黎 → 里斯本 → 京都）沿大圆航线画出樱桃红线，航线头部有一个圆点；旅程邮票标记在航线到达时带旋转弹出。只播放一次。
- **地图镜头**：点击地点时用 flyTo（先拉远再推近，约 2.2 秒）飞向目标；信息卡淡入上移。减少动态效果时改为直接跳转。

### 8.7 灯箱

- 打开：被点击的照片通过 View Transitions 共享元素平滑放大到灯箱位置（560ms，`--ease-out`），背景墨绿遮罩模糊。
- 切换：新照片按方向从侧面 24px 滑入。
- 关闭：大图缩回原照片位置，焦点回到触发元素。
- 不支持 View Transitions 的浏览器直接打开或关闭，功能不受影响。

### 8.8 减少动态效果

开启系统「减少动态效果」时：不播放开场；不播放幕布、逐字、邮戳、航线和共享元素动效；地图镜头直接跳转、航线直接完整显示；照片直接替换；滚动出场内容直接显示；平滑滚动改为跳转；跟随光标和 3D 倾斜关闭。状态变化（选中邮票、选中标记、地图标记）仍立即呈现。

### 8.9 性能约束

- 照片转场前用 `decode()` 预解码新图，幕布合拢与解码都完成后才换图。
- 不使用常驻 `requestAnimationFrame` 循环；跟随标签和地图飞行点只在播放期间逐帧更新。
- 触屏设备不绑定跟随光标与 3D 倾斜。

## 9. 世界足迹地图（V0.3 新增）

用户要求：更符合真实物理世界，展示真实世界地图，支持缩放查看地理位置标记；点击有相册的目的地时联动上方旅程。

### 9.1 技术选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 地图引擎 | MapLibre GL JS 5.24.0（BSD-3 开源），原型内置于 `docs/prototypes/pistachio-cherry/vendor/` | 矢量渲染，可完全改色；支持 3D 地球投影；无需账号 |
| 底图数据 | OpenFreeMap 矢量瓦片（OpenStreetMap 数据，OpenMapTiles 结构），样式 `liberty` 改色 | 免费、无需 API key；从全球到街道级 |
| 投影 | 地球（globe），放大后自动过渡为平面 | 低缩放时呈现真实球体，强化「真实物理世界」 |
| 航线 | 按大圆插值计算 | 线条沿地球真实曲率，而不是平面直线 |

曾考虑的替代方案：继续使用手绘 SVG（无法缩放到城市与街道）；D3＋Natural Earth 国家边界（可缩放但没有城市与街道细节）；商业地图服务（需要账号和费用，样式受限）。

### 9.2 地图配色（基于第 3 节色板）

| 图层 | 颜色 | 说明 |
| --- | --- | --- |
| 陆地 | `#EAF3C4`（开心果浅调） | 背景层 |
| 地形阴影 | 原始晕渲去色，透明度随缩放 0.34 → 0.06 | 保留山脉起伏，低缩放时更明显 |
| 海洋、湖泊 | `#FFD3E6`（草莓粉浅调） | 品牌化的大胆处理 |
| 河流线 | `#FFB8D6` | |
| 公园、林地、草地 | `#D2E879`，55% | |
| 道路 | 白色；高速 `#FFBEDB`；外描边墨绿 12% | 只有高速用粉色，避免城市级画面杂乱 |
| 建筑 | `#DCE9AC` | 不使用 3D 建筑 |
| 国界 | 墨绿 42% | |
| 文字 | 墨绿，浅叶白描边 | 优先简体中文名（`name:zh-Hans` → `name:zh` → 本地名 → 英文名）；中日韩字形用本机 Noto Sans SC／苹方渲染 |
| 隐藏 | 商户图标、道路编号盾牌、单行箭头、机场、部分用地 | 保持刊物式的干净画面 |
| 地球大气 | 浅叶白到草莓粉的地平线渐变，7 级以后消失 | |

### 9.3 三类地点

| 类型 | 标记 | 显示条件 | 点击行为 |
| --- | --- | --- | --- |
| 有相册的旅程 | 迷你草莓粉齿孔邮票，内部为该旅程的几何图案；旁边标签「拉丁名＋中文名」 | 缩放 < 6 级；地球视角下只显示选中旅程的标签 | MAP-02 |
| 旅途站点 | 浅叶白圆点、墨绿描边；属于当前旅程时为樱桃红描边，被选中时为樱桃红实心；标签「站名＋日期」 | 缩放 ≥ 6 级；4.5 级起按旅行顺序用墨绿虚线连接 | MAP-03 |
| 足迹（无相册） | 墨绿虚线圆圈，虚线边标签 | 所有缩放 | MAP-04 |

转到地球背面的标记完全隐藏，不显示半透明残影。

### 9.4 交互约束

- **协作手势**：普通滚轮不缩放地图，避免读者滚动页面时被地图「卡住」；按住 ⌘／Ctrl 滚动或触控板捏合才缩放，手机需双指。提示文字已改为中文。
- 关闭旋转与倾斜，保持北向朝上，降低迷失感。
- 信息卡固定在地图左下角；镜头飞行会给信息卡预留边距，目标不会被遮住。
- 地图画布本身对读屏不友好，因此地图下方提供按时间排列的完整地点按钮列表（MAP-08），标记本身也是带说明的按钮。
- 地图组件或瓦片服务不可用时，显示说明文字，时间线仍可使用。

### 9.5 数据要求（正式实现）

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| `geo` | 旅程 | 已有 |
| `route[].geo` | 每个站点 | **新增**：站点经纬度 |
| `hasAlbum` 或相册关联 | 地点 | **新增**：区分「有相册的旅程」与「足迹」 |
| `footprints[]` | 独立列表 | **新增**：没有相册的到访地点（名称、拉丁名、日期、经纬度） |
| 照片与站点关联（可选） | 相册照片 | 若录入，可在 MAP-03 时直接打开该站的照片；原型目前打开该旅程相册的对应序号 |

### 9.6 风险与正式实现建议

- **第三方瓦片依赖**：OpenFreeMap 为公益服务，没有 SLA；测试中出现过个别瓦片请求失败（网络波动，地图其余部分正常）。正式上线建议自托管 PMTiles 瓦片文件（或使用付费、有 SLA 的服务），样式与改色逻辑不变。
- **署名义务**：必须保留「OpenFreeMap © OpenMapTiles Data from OpenStreetMap」署名（原型右下角已保留）。
- **体积**：MapLibre 约 1MB（未压缩），原型在读者接近地图时才加载瓦片；正式实现应同样延迟加载脚本本身。
- **WebGL**：不支持 WebGL 的设备会显示降级说明和时间线。

## 10. 正式实现的检查点

- [ ] 首页与选定原型的配色、字体及左右栏目关系一致。
- [ ] 邮票悬停不改正文，点击可联动照片、摘要、路线、相册和地图。
- [ ] 切换旅程不改变全站主配色。
- [ ] 主照片和相册均可打开灯箱；关闭时恢复焦点和位置。
- [ ] 上一段／下一段、键盘操作和地图选择保留。
- [ ] 手机使用两列邮票布局，标题、照片、相册和地图无横向溢出。
- [ ] 减少动态效果偏好生效，并完成实际文字背景对比度检查。
- [ ] 开场、选择、滚动、灯箱动效按第 8 节时序实现，且没有循环动画。
- [ ] 连续快速切换旅程时，照片与文字始终属于最后一次选择的旅程。
- [ ] 樱桃红文字只出现在 ≥ 24px 的展示标题上。
- [ ] 世界地图可从地球缩放到街道级；三类地点按第 9.3 节显示和响应。
- [ ] 点击有相册的地点或站点会联动上方旅程，站点在路线中标为锚点；无相册地点不改变旅程。
- [ ] 普通滚轮不劫持页面滚动；地图下方时间线可完成全部地点操作。

## 11. 原型验证记录

使用本机 Chrome（Playwright 驱动）在 1440×900 与 390×844（触屏）下验证：

- 控制台与页面错误：0。
- 点击邮票切换巴黎：标题、照片、编号、`aria-pressed` 同步更新；转场中途截图确认双层幕布覆盖。
- 连续快速点击四枚邮票：最终标题与照片均为最后一次选择（里斯本），幕布停在画面外。
- 邮票区方向键：切换旅程，焦点跟随到新邮票。
- 相册打开灯箱、方向键翻页、Esc 关闭：灯箱内方向键不改变旅程；关闭后焦点回到原照片。
- 地图：进入视口后航线与标记按序出现；点击标记回到旅程详情。
- 减少动态效果：选择后照片立即替换。
- 390px 宽度：无横向溢出（修正了邮戳超出屏幕的问题）。
- 开场：字体缓存后在约 0.5 秒、1 秒处截图，确认标题逐字升起、邮票落下、幕布未开。

**V0.3 地图验证（同一环境，WebGL 为软件渲染）：**

- 地图载入、23 个标记（4 旅程、16 站点、3 足迹）落在正确地理位置（地球视角、京都、奈良、巴黎街道级截图核对）。
- 修正一处缺陷：标记样式覆盖了 MapLibre 的绝对定位，导致标记依次向下错位；修正后对齐。
- 点击巴黎旅程标记：上方切换到巴黎，信息卡同步。
- 点击奈良站点：上方切换到京都，路线中「奈良 04.21」成为锚点，镜头到街道级。
- 点击上海（无相册）：上方旅程不变，信息卡显示无相册说明。
- 上方点冰岛邮票：地图选中标记与信息卡同步为冰岛。
- 信息卡「打开相册」打开对应旅程灯箱；缩放按钮与「全球」可用；390px 宽无横向溢出。
- 控制台无脚本错误；网络波动时个别街道级瓦片请求失败（已记入风险）。

未验证：Safari 与 Firefox 的表现（View Transitions、CSS 滚动时间线在部分浏览器不可用，已有降级）、真实移动设备性能、读屏软件的实际朗读效果。
